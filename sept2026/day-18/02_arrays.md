# Next Permutation

## Problem
Rearrange to the next lexicographical permutation.

## Example
```
Input: [-6, 8, 5, 36, 37, 22, 1, 0, 20, 48]
Output: (compute according to problem statement)
```

## Constraints
- Reasonable input sizes for interview settings (`n` up to ~10^5 unless noted)
- Aim for better than naive O(n^2) when possible

## Hint
Find pivot, swap, reverse suffix.

Arrays & Hashing
