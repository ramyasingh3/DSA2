# Majority Element II

## Problem
Find all elements appearing more than floor(n/3) times.

## Example
```
Input: [26, 26, -17, 0, 13, 4, 36, 10, 6, 9, 10]
Output: (compute according to problem statement)
```

## Constraints
- Reasonable input sizes for interview settings (`n` up to ~10^5 unless noted)
- Aim for better than naive O(n^2) when possible

## Hint
Boyer-Moore voting with two candidates.
