# Decode String

## Problem
Decode k[encoded] nested strings.

## Example
```
Input: [44, 33, -19, 20, 44, 34, -3, -2]
Output: (compute according to problem statement)
```

## Constraints

- Aim for better than naive O(n^2) when possible
