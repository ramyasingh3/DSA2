# Add Two Numbers II

## Problem
Add numbers stored MSB-first without reversing inputs.

## Example
```
Input: [32, 41, 48, 20, 31, 0, -6, 15, -7, 47]
Output: (compute according to problem statement)
```

## Constraints
- Reasonable input sizes for interview settings (`n` up to ~10^5 unless noted)
- Aim for better than naive O(n^2) when possible

## Hint
Stacks or lengths + recursion.

## Topic
Linked Lists
